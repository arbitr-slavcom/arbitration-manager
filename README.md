# Arbitration Manager

Русскоязычный интерфейс для арбитражных дел и банкротства. MVP — только просмотр данных.

## Запуск

1. Node.js 20+; `npm install`.
2. Скопируйте `.env.example` в `.env` и заполните publishable key Supabase (никогда не service_role).
3. `npm run dev`.
4. Войдите через Supabase Auth. Пользователь должен иметь запись в `au.staff` и соответствующие права RLS.

## База

Supabase: `pevbeueyqkieirooiemu`, схема `au`. Перед использованием настройте Exposed schemas и GRANT для `authenticated`, проверьте RLS. Не открывайте доступ `anon`.

## Ограничения

Только просмотр до 200 записей раздела. Редактирование, загрузка файлов и доставка напоминаний не реализованы. Не используйте для реальных персональных данных до аудита безопасности.
